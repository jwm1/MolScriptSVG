Installing MolScriptSVG 2.3

The supported build described here is for Linux. The executables are molscript and molauto. The full build includes OpenGL, EGL and PNG/JPEG/GIF/SGI/EPS images; the basic build needs no graphics libraries.

Source distribution

Use the GitHub repository or the MolScriptSVG_2.2.tar.gz source archive. Generated examples are included. Build commands below are run from the repository root.

Dependencies

A C compiler, GNU Make and Bison are needed for development. The complete build also uses pkg-config, OpenGL/GLU/GLUT, X11, EGL, libpng, libjpeg, libgd and zlib. FreeType is optional. Debian/Ubuntu packages:

sudo apt install build-essential bison pkg-config freeglut3-dev \
  libgl1-mesa-dev libglu1-mesa-dev libegl1-mesa-dev libx11-dev \
  libpng-dev libjpeg-dev libgd-dev zlib1g-dev libfreetype-dev

Build choices

Complete build

make -C code -j4

This uses bundled bitmap labels. To enable FreeType fonts:

make -C code -j4 USE_FREETYPE=1

Basic build

make -C code clean
make -C code -f Makefile.basic -j4

The basic build supports PS, SVG, MetaPost, POV-Ray, Raster3D, VRML, X3D and WebGL export, but not interactive OpenGL or raster-image export. Clean before switching between basic and complete builds. The FreeType toggle alone is tracked automatically.

Headless images and labels

EGL image rendering does not need a running X server. If EGL initialization fails, the default auto mode tries GLUT, which needs a display. Force either path with MOLSCRIPT_IMAGE_BACKEND=egl or MOLSCRIPT_IMAGE_BACKEND=glut.

cd examples
env -u DISPLAY MOLSCRIPT_IMAGE_BACKEND=egl ../molscript \
  -png -labelfont bitmap -in ras_gdp.in -out ras_gdp_bitmap.png
env -u DISPLAY MOLSCRIPT_IMAGE_BACKEND=egl ../molscript \
  -png -labelfont freetype \
  -fontfile /usr/share/fonts/truetype/dejavu/DejaVuSans.ttf \
  -in ras_gdp.in -out ras_gdp_freetype.png

FreeType requires the optional build above. Both paths currently use monochrome glyphs. These options do not affect SVG or PostScript text.

Examples and tests

Open the example gallery locally. From the repository root, sh scripts/regenerate-examples.sh regenerates scene files and SVG PNG previews, and POV-Ray previews when POV-Ray is installed. SVG rasterization uses CairoSVG or Inkscape.

See test instructions, README and 2.2 release notes.
