Software libraries used in MolScript

GLUT library

  • freeglut is the maintained OpenGL Utility Toolkit implementation used by the complete build. It implements the GLUT API originally developed by Mark Kilgard.
  • See also "OpenGL Programming for the X Window System", the book Mark Kilgard has written about OpenGL and the X window system.

JPEG library

  • Independent JPEG Group, the original libjpeg implementation.
  • libjpeg-turbo, a compatible implementation commonly provided by system libjpeg development packages.

PNG library

  • libpng, the PNG reference library.
  • zlib, its compression dependency.

GIF library

  • GD Graphics Library (libgd), the current project site, with API documentation. MolScriptSVG uses libgd to write GIF files. Install a current development package.
  • The old GIF/LZW patent restrictions have expired. The historical advice to use non-LZW gd 1.3 is obsolete; see the updated format notes and sources.

Other relevant sites

Raster3D

  • Raster3D package and source (Debian).
  • Raster3D manual (Debian-hosted). Raster3D was developed by David J. Bacon and Ethan A. Merritt. These links replace the unavailable University of Washington pages.

OpenGL

  • OpenGL at the Khronos Group.
  • The Mesa 3D Graphics Library, open-source implementations of OpenGL and other graphics APIs.

PostScript

  • PostScript, at the official Adobe Inc. website.
  • Ghostscript, a PostScript and PDF interpreter.

VRML 2.0

  • X3D at the Web3D Consortium, the successor to VRML.
  • The VRML97 specification, the ISO codification of VRML 2.0.

SGI (aka RGB) image file

  • The original SGI image specification (Paul Bourke mirror).
  • SGI format record at the UK National Archives.

GNU software

  • The GNU Project.

Protein 3D structure data

  • The Protein Data Bank (PDB) at RCSB. This is the scientific data bank where published protein 3D coordinate data sets are deposited by the scientists and from where the data sets can be retrieved by anyone. The specification of the PDB coordinate file format is available. The 3D data sets can be searched in different ways.
